# 这一场

手机优先的演员随身对词台。先完成一次练习，再决定是否记录感受。React + TypeScript + Vite，原生 IndexedDB 保存文字与视频 Blob；没有业务后台、AI 自动解读、统计追踪或上传接口。

## 新版怎么用

1. 点“粘贴几句，另开一段”，每行用 `我：` / `对手：` / `动作：` 或角色名标记。选择本人角色并核对预览，不要求填写场号、前情或人物分析。
2. 点开始，听对手、自己接；每次接句都由本人点击，不监听说话或自动判定完成。本人台词默认遮住，可只看一句提示。
3. 选择起止句、换练习方、重读、调语速或手动循环。点“记住这段与当前位置”后，刷新首页可找到当前项目最近保存的有效位置。
4. 剧本更新时打开“改词”，粘贴新版，先看逐行增删改，再确认保存为新版本，直接练改动与必要的提示句。改前改后各留独立快照。
5. 处境提示、旧戏前卡和A/B摄录都放在可选入口，不挡在练习之前。原有历史仍在“我的处理”中。

初次可以点“先用10句虚构台词试试”，不提供私人素材。开发提示词见 [UPGRADE-PROMPT.md](./UPGRADE-PROMPT.md)，本次验证见 [QA-UPGRADE.md](./QA-UPGRADE.md)。原提案保留初版构想，并已标注工具定位更新。

## 运行

需要 Node.js 22.12+ 或 24+。

```sh
git clone https://github.com/zhanyina1205-ai/one-scene.git
cd one-scene
npm ci
npm run dev
```

电脑打开 `http://localhost:5188/`。手机与电脑同一局域网时，打开终端输出的 Network 地址。电脑需保持运行且防火墙允许访问。

手机请优先用发布后的 **HTTPS** 网页，在正常模式的 Safari / Chrome 中打开。局域网HTTP的摄录及部分安全上下文API可能不可用，不作为可靠手机入口。电脑开发使用localhost；不要把手机自己的localhost当作电脑地址。原私有托管入口仍需网站所有者账号。

```sh
npm test
npm run build
npm run preview
```

生产输出在 `dist/`，可部署到 HTTPS 静态托管。所有业务数据仍留在访问网站的浏览器内；本地、线上、不同浏览器和不同设备之间不会同步。

## GitHub 同步与发布

推送到 `main` 会执行 `.github/workflows/pages.yml`：安装锁定依赖、运行小工具与提案测试、构建两个网页、发布 `dist/` 到 GitHub Pages。拉取请求只做测试构建，不发布。也可以在 Actions 中手动运行该工作流。

提案源码和 AI 情境配图放在 `proposal/`，不包含原私有站点的身份配置、访问凭据或个人素材。`npm run build` 同时构建小工具和自包含提案 HTML，将后者放入 `dist/proposal/index.html`。修改 `proposal/source/` 后按同一流程提交发布即可；原 `one-scene-proposal` 本地目录和私有预览站点不受此次发布影响。

小工具保持原来的网址和数据库名称，不更改或清理已保存资料。提案只提供虚构交互讲解，不读取或写入小工具的 IndexedDB。它与小工具现在同源，同源页面在技术上并不是浏览器安全隔离的两个空间。

```sh
git add .
git commit -m "Update mobile web app"
git push origin main
```

发布前检查暂存文件，勿提交真实剧本、视频、个人笔记或密钥。视频、数据库、备份目录和 `.env` 默认忽略。浏览器里的 IndexedDB 不在源码目录中，GitHub 同步的是代码，不是用户数据。

Vite 使用相对资源路径；根域名与 `/one-scene/` 子路径都能部署，主页图标和 manifest 也使用相对路径。没有配置云端数据同步或自动双向合并源码。

## 已实现

- 新主导航：开练、对词台、改词、我的处理；支持空白项目、少字段粘贴开练和详细场次录入。
- 标记台词的归属核对、默认遮词、单句提示、逐句接词、起止范围、换练习方、手动循环、主动保存位置。只朗读当前对手部分，动作不读。
- 系统本地中文朗读、声音与语速选择、取消、失败和超时提示；没有本地声音时手动练习继续使用。切页、换场、后台和视频播放会停止朗读。
- 旧新台词逐行比对；旧文不匹配当前场次时只比较不覆盖。确认保存新版，留下前后快照、提取含提示与回应的改动区间，可从单处或整组练习。
- 保持原网址与数据库，不迁移或删除旧数据；新版字段可选，旧工作区无需重建。保存新版不覆盖旧A/B草稿、处理和媒体引用。
- 以下旧功能保留在可选入口：
- 前情、角色已知 / 误以为知道 / 待确认信息，分别记录原文依据或本人确认。无依据且未本人确认时仍展示为待确认。
- 原文手动粘贴，按明确的“我：”“对手：”“动作：”标记拆分练习段落，支持遮住本人台词。
- 戏前卡直接携带场次进入试演台；A/B 出发点、试后感受、摄录或视频导入、原片下载、预览与重新录制。
- 切换 A/B 对照；播放另一条视频时暂停之前的视频，避免叠音。
- 保存 A、B 或保留两版，个人理由准确回写；历史保留完整的场次、版本、两版想法、媒体引用、笔记与时间快照。
- 草稿自动保存与手动重试；导航前等待保存，摄录和未处理片段阻止误离开。页面关闭由浏览器提供未保存提示，不承诺拦住系统强杀。
- 更新原文、处境或版本后提醒复查旧处理，不自动套用新版本。旧草稿可明确替换为当前版本的新草稿。
- IndexedDB 跨文字与媒体的事务保存，失败不更新“已保存”状态；空间不足、授权拒绝、缺少摄录能力、文件无法解码均提供提示。
- 视频保存失败时暂留本页，可重试、先下载或主动放弃；文字仍需用户在失败页重试，不能关闭页面后找回未保存输入。
- 删除前明确确认，媒体仅在不再被任何历史或草稿引用后回收。历史视频按需读取，不在所有折叠记录中预加载。
- 首次提供《渡桥》/ 沈知微的三场虚构演示，可另开“周宁 / 林舟”十句演示，无真实演员资料。

## 数据与隐私

数据库：`one-scene-private-v1`（仍为版本1）。`workspace` 储存项目 / 场次 / 草稿 / 历史 / 笔记，新增可选 `practice` 位置与 `revisions` 改词快照；`media` 储存视频 Blob。没有视频 localStorage，没有默认网络上传。

朗读只选用浏览器返回 `localService: true` 且语言为中文的声音，不选择远程声音、不调用第三方TTS、不请求麦克风。声音实际可用性取决于系统、浏览器与安装的语音包；我们不能审计操作系统内部实现。无声、报错或超时可直接手动接句。系统朗读不是对手演员的真实表演。多人场次暂把所有非本人角色合为“对手方”，换方不是选择单一角色。

仅保存主动确认的练习位置。单句临时提示、未保存的设置和改词输入不承诺刷新后恢复。改动段组合暂存为本轮计划；记住位置只保存当前区间。台词或版本改变后旧位置不套用。逐行差异基于文本与归属，不是语义分析；一次最多200段 / 20000字。

本地存储不是云备份，也不是加密保险箱。清理网站数据、无痕模式、系统回收空间或更换网址 / 浏览器，都可能导致内容无法恢复。重要视频请下载原片。MVP 没有整库备份、跨设备迁移、离线缓存或云同步；请避免多个标签页同时修改同一份数据。
