# 这一场 · 产品试用提案

手机优先、适合桌面讲解的独立 HTML 提案，与小工具共同部署在同一个 GitHub 仓库。

- 提案：https://zhanyina1205-ai.github.io/one-scene/proposal/
- 小工具：https://zhanyina1205-ai.github.io/one-scene/
- 仓库根目录运行 `npm ci`、`npm test`、`npm run build`，可测试并构建两个页面。
- 提案单独构建：`npm --prefix proposal run build`；输出 `proposal/dist/index.html`。
- 提案单独预览：`npm --prefix proposal run dev`，访问终端显示的本地网址。
- 提案单独测试：`npm run test:proposal`。

## 内容与交互

为什么做 → 工作与独处片刻 → 为什么需要本人使用 → 虚构场次流程 → 预期帮助 → 隐私边界 → 实现与验证状态 → 试用邀请。

情境切换、A/B 示例、处理选择、模拟回写、复制链接与 HTML 下载可操作。演示状态仅在内存中，刷新清除，不调用摄像头、不读取或写入小工具本地数据库。真实摄录与素材保存请打开小工具。

所有角色、台词与想法均为虚构示例。配图由 AI 生成，不代表李一桐本人或真实生活，不构成官方合作或本人背书。素材与提示词见 `ASSETS.md`，实际浏览器检查与限制见 `QA.md`。

## 分享

构建后的 `index.html` 是自包含文件，内嵌图片、样式与脚本，可下载后直接发送。复制链接受浏览器权限限制，失败时会显示可手动复制的地址。打印调用浏览器打印，可按浏览器能力存为 PDF；未验证所有打印分页或手机浏览器。

本目录不包含任何 Sites 的身份配置、密钥、真实剧本、个人笔记或视频。网页公开不等于个人录入资料上传。
